# 03 — Tech stack

Every choice, why it was made, and what was rejected. A choice without a rejected alternative is a habit,
not a decision.

## Frontend

| Choice                                   | Why                                                                                                                                                        | Rejected                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Next.js 16, App Router**               | House convention. RSC renders the catalogue on the server while motion stays in client islands — exactly the split a cinematic commerce site needs.        | **Remix** — fine router, no RSC story. **Astro** — islands are a good fit but the ecosystem for a long-lived cart and auth is thinner. **SPA** — no SEO on drop pages, which are the shareable asset.                                                                                                       |
| **Lenis + GSAP ScrollTrigger**           | ScrollTrigger is the only mature pinning + scrub primitive. Lenis gives the weighted scroll that makes a scrub feel like film rather than a slider.        | **Framer Motion** `useScroll` — no pin primitive, visibly janky on long scrubs. **Three.js** — a gigabyte-class dependency to rotate a t-shirt that 72 images do better. **CSS scroll-driven animations** — kept as progressive enhancement; Safari support is still partial, so it cannot be the baseline. |
| **Canvas image sequence** for turntables | What the reference site actually does: a sticky stage, a pre-rendered sequence, one canvas. Decodes off-thread, never reflows, degrades to a single image. | **Video scrubbing** — seeking is unreliable across browsers and awful on Android. **WebGL model** — needs a 3D asset per garment we do not have and cannot generate per drop in a day.                                                                                                                      |
| **Tailwind v4 + `libs/ui` tokens**       | Tokens are the contract; Tailwind is just the shorthand. A lint rule bans raw hex outside `libs/ui`.                                                       | **CSS Modules** — no shared token enforcement. **styled-components** — runtime cost on a page already spending its budget on motion.                                                                                                                                                                        |
| **shadcn/ui for admin only**             | The admin is a tool: dense, accessible, boring, fast to build. It deliberately does not share the storefront's motion.                                     | Building admin components by hand — weeks of work for no differentiation.                                                                                                                                                                                                                                   |

## Backend

| Choice                                                    | Why                                                                                                                                                                                        | Rejected                                                                                                                                                                                        |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **NestJS 11 + Fastify**                                   | House convention. DI is exactly right for swappable POD and payment adapters, and it gives the worker a real home.                                                                         | **tRPC only** — no worker story, no webhook surface, no domain boundary. **Next route handlers as the API** — ties the business to the rendering framework and makes the mobile app a rewrite.  |
| **Supabase** — Postgres, Auth, Storage, Realtime          | One service instead of four. Auth gives phone OTP free, which matters in India far more than email. Storage holds artwork and frame sequences. Realtime drives the live admin order board. | **Self-hosted Postgres + NextAuth + S3** — three things to run and secure for one person. **Firebase** — document model fights an order/line-item schema that is relational by nature.          |
| **Prisma** as the ORM                                     | House convention (`classroom-metaverse/libs/db`). NestJS is a long-lived process so Prisma's cold-start weight is irrelevant, and migrations are a first-class artifact.                   | **Drizzle** — lighter and good, but breaks house convention for no gain in this shape. **Supabase client as the ORM** — no migration story, no type-safe joins, no transactions worth the name. |
| **The API is the only database writer**, via service role | Authorization in one testable place beats policies scattered across tables. RLS is reserved for the few tables a client reads directly.                                                    | **RLS everywhere** — policy sprawl, hard to test, and a performance cliff on joins.                                                                                                             |
| **BullMQ + Redis** worker                                 | POD submission, 72-frame rendering and trend ingest are all slow, retryable and bursty. Retries with backoff are the whole point.                                                          | **Supabase Edge Functions** — a 10s ceiling makes frame rendering impossible. **In-process cron** — loses jobs on deploy, and a lost POD submission is a lost order.                            |

## Commerce

| Choice                        | Why                                                                                                                                      | Rejected                                                                                                                                                                                                        |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Razorpay**                  | UPI is the conversion unlock in India, and Razorpay's UPI, cards and COD coverage plus webhook tooling is the best of the local options. | **Stripe** — weak UPI, no COD, and the business banks in India. **Cashfree** — genuinely competitive; Razorpay wins on documentation and webhook replay tooling.                                                |
| **Printrove** (first adapter) | India printing, 3–5 day delivery, COD settlement, DTF quality adequate at this price point.                                              | **Printful** — ₹2,500 landed cost into India plus customs; it is the reference site's provider and the wrong one for this market. **Qikink** — close second, kept as the next adapter if Printrove's SLA slips. |
| **`PodProvider` port**        | India first does not mean India only. The port is how global arrives later without touching the order domain.                            | A direct Printrove client in the order service — cheap today, a rewrite the first time we ship abroad.                                                                                                          |

## Tooling

| Choice                          | Why                                                                                                                                      | Rejected                                                                                                                                                                                                                     |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Nx 23 + pnpm workspaces**     | House convention. `nx affected` keeps CI honest, module boundaries keep `libs/motion` and `libs/pod` from being walked around.           | **Turborepo** — used in `country_dairy` and `smart_expense_tracker`; Nx's boundary enforcement and generators are worth the extra concept count here. **No monorepo** — four deployables sharing types makes that untenable. |
| **Vitest + Playwright**         | House convention, and Playwright doubles as the visual-regression tool for `libs/motion`.                                                | Jest — slower, and another config to maintain alongside Vite.                                                                                                                                                                |
| **A cached `budget` nx target** | Cinematic everywhere only stays honest if a regression fails the build, not a review. Mirrors `classroom-metaverse/apps/web/budget.mjs`. | Lighthouse CI alone — measures the built page but not the bundle, and is too noisy to gate on.                                                                                                                               |

## Deferred, deliberately

- **X/Twitter as a radar source** — the API is priced out of reach. Reddit, HN, Google Trends and YouTube
  cover the same signal at zero cost. Revisit if pricing changes.
- **International shipping** — the port exists; the adapter does not.
- **Native app** — Phase 8, reusing `@nowcore/shared` and the Supabase client.
